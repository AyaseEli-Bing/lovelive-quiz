# LoveLive! 角色性格测试（μ's / Aqours）

选团 → 回答该团专属的 10 道情景题 → 得到团内匹配度最高的成员，并查看九人完整排行。
纯静态站点：零依赖、无构建步骤。

线上地址：<https://ayaseeli-bing.github.io/lovelive-quiz/>

## 功能

- μ's / Aqours 双团菜单，每团 9 名成员
- 每题 4 个选项，按成员特质加权计分，结果附九人完整匹配度排行
- 结果编码在 URL hash 中：可直接分享、刷新可复原
- 深色模式：默认跟随系统，右上角可手动切换并记住选择
- 键盘可用：`1`–`4` 作答，`Backspace` 回上一题
- 头像加载失败时自动回落到成员应援色色块

## 本地预览

```bash
python3 -m http.server 8000
```

然后打开 <http://127.0.0.1:8000/>

- 成员资料（姓名、生日、血型、学年、所属小队、应援色名）依据[萌娘百科](https://zh.moegirl.org.cn/)条目整理；性格描述为自行改写。`LoveLive!角色颜色` 模板与成员条目正文对应援色的口径不一致时，以条目正文为准并在卡面注明。
